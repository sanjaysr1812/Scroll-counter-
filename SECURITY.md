# Security Policy

## Reporting a vulnerability

ScrollMeter uses Android accessibility capabilities for its documented swipe-counting purpose. Reports should avoid sharing screen contents, messages, account details, or other personal data. Please report suspected vulnerabilities privately to the repository owner rather than publishing exploit details. This repository does not promise a formal response-time SLA.

When reporting, include the affected version or commit, a concise description of the impact, and safe reproduction context. Redact tokens, passwords, personal information, and production data.

## Supported versions

Security fixes are handled on a best-effort basis for the current default branch.
